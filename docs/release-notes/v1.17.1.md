# ProcessNetMonitor v1.17.1 — 修复悬浮窗悬停提示在部分注入环境下永久失灵（看门狗自愈）

## 修复

- **悬浮窗悬停提示永久失灵（需重启 TM 才能恢复）**：部分会向其他进程注入 DLL 的工具（已实测两种触发：GamePP 游戏加加在「睡眠唤醒 + 切换显示器」后重装窗口钩子；远程桌面接管会话后的一次不明注入）会把本插件悬浮窗的消息处理函数替换掉。此后鼠标悬停 TrafficMonitor 窗口永远不再弹出悬浮窗，任务栏钉住也无效，且没有任何报错——只能重启 TrafficMonitor。本版在插件内新增一个不可见的看门狗窗口：每秒自检悬浮窗的消息处理是否被外部替换，发现被顶立即自动恢复原状并重新挂起悬停检测，**最长 1 秒内悬浮窗自动回到可用状态，全程无需重启**（实验室注入复现实测自愈耗时 984–1000ms，可重复自愈）

选择与你的 TrafficMonitor 主程序位数一致的 DLL，放入 TM 的 `plugins/` 目录。**本版无新增界面词条，所有用户从 v1.16.0+ 升级直接替换 DLL 即可**，语言文件无需更新。

## 安装前提

1. Windows 10/11（推荐 64 位）
2. TrafficMonitor 主程序（插件版）
3. 插件以管理员权限运行时可启用 ETW 内核采集（更准）；普通权限自动回退传统采集并提示
