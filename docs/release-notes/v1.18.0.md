# ProcessNetMonitor v1.18.0 — 悬浮窗背景效果（亚克力 / 模糊 / 透明度）、文字颜色自动适配背景、视觉与图标打磨

## 新增

- **悬浮窗背景效果与透明度**：插件设置新增「悬浮窗背景」与「悬浮窗透明度」两项。背景可选**亚克力**（磨砂 + 细腻噪声质感）、**模糊**（纯磨砂）、**透明**（真半透明，直接透出桌面）、**不透明**四档；透明度滑条（10–100）控制面板色的浓淡，亚克力/模糊档同样适用。磨砂由系统实时合成——悬浮窗背后的视频播放、网页滚动**实时透进模糊层**，无需插件刷新。Windows 10 1703 之前的系统上亚克力/模糊自动降级为透明档
- **文字颜色自动适配背景**：半透明/磨砂背景下，悬浮窗文字的深浅随背后背景亮度自动翻转——浅背景自动换深色字、深背景换浅色字，拖动悬浮窗时实时重判；判定只作用于文字本身，「查看详细」按钮、边框等界面元素保持主题配色不变。不透明模式下不参与
- **悬停反馈**：悬浮窗「实时上传/实时下载」两个分区标题条与「查看详细」按钮在鼠标悬停时高亮，按钮上光标变为手型，点击目标更明确
- **视觉打磨**：悬浮窗文字改用微软雅黑 + ClearType 渲染，中文笔画更干净；进程图标改为按实际显示尺寸高质量提取，消除此前的放大锯齿；进程名与流速之间的留白收窄，同样宽度下能显示更多内容

## 修复

- **悬浮窗悬停提示在部分注入环境下永久失灵**（v1.17.1）：部分会向其他进程注入 DLL 的工具（已实测两种触发：GamePP 游戏加加在「睡眠唤醒 + 切换显示器」后重装窗口钩子；远程桌面接管会话后的一次不明注入）会把本插件悬浮窗的消息处理函数替换掉，此后鼠标悬停永远不再弹出悬浮窗且无任何报错，只能重启 TrafficMonitor。本版在插件内新增不可见的看门狗窗口：每秒自检悬浮窗的消息处理是否被外部替换，发现被顶立即自动恢复，**最长 1 秒内悬浮窗自动回到可用状态，全程无需重启**
- **Windows 7 下插件加载失败**（v1.12.0 起回归）：插件引用了 Windows 8 才提供的系统函数，导致 Win7 上加载即失败。现改为运行时按需加载，Win7 恢复可用；亚克力/模糊效果在不支持的系统上自动降级为透明档
- **设置对话框英文界面标签错位**：英文标签文字较长时钻到输入控件下方，标签与控件现已成对排列
- **界面语言「跟随系统」时无法恢复中文**：语言切换的重载路径未清理旧词表，切回后界面停留在旧语言；已修复

## 性能优化

- **进程图标按需加载**：图标提取不再阻塞界面绘制——悬浮窗弹出、详情窗首次打开（几十上百个进程）时先显示内容、图标随后陆续补齐；位于网络路径/已断开的映射盘上的程序此前可能让界面卡顿数秒，现在直接使用轻量图标，不再等待网络

## 安装前提

1. Windows 7 及以上（Windows 10/11 功能完整，推荐 64 位；亚克力/模糊效果需 Win10 1703+，更低系统自动降级透明档）
2. TrafficMonitor 主程序（插件版）
3. 插件以管理员权限运行时可启用 ETW 内核采集（更准）；普通权限自动回退传统采集并提示

## 已知说明

- TUN 代理模式下，走代理的应用流量归属代理进程（如 mihomo），应用侧 TUN 重复流量不显示（与 AppNetworkCounter 一致）
- 代理进程与应用之间的虚拟转发流量（TUN 用户态）无法通过内核 ETW 观测，不显示
- 与 AppNetworkCounter 等 ETW 工具共用时：先启动的一方占用 NT Kernel Logger；后启动的 TM 进入附加模式（悬浮窗有黄色警告提示）
- ETW 占用者检测为尽力而为（Windows 无官方 API，普通权限下为已知工具名单识别）
- IP 归属地库（ip2region）首次使用时自动下载，失败会提示；可关闭或配置代理
- Windows 7 上插件恢复可用（基础功能），亚克力/模糊背景效果自动降级为透明档
