# ProcessNetMonitor v1.10.0-test1 — 开机闪退修复测试版

⚠️ **测试版**：请重点验证**开机自启**场景下是否还会卡死/闪退。

## 相对 v1.10.0 的修复

- **修复开机自启卡死/闪退**（0xc0000374 堆损坏）：悬浮窗/详情窗口数据更新改为 PostMessage 到各自 UI 线程执行，消除定时器线程与绘制线程的跨线程 vector 访问
- **崩溃诊断**：发生未处理异常时自动生成 `crash.dmp` + `crash.dmp.log`（含 failfast 捕获，双保险）
- **进程名解析通用化**：无法获取镜像路径的进程（System、Registry、受保护进程等）显示真实进程名（Toolhelp 兜底），不再显示 `<pid>`
